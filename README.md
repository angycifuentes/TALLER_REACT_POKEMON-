# TALLER_REACT_POKEMON- Taller de React usando Pokemon 

¿Que es el proyecto? 

Este taller de  Pokémon con React es una aplicación web interactiva desarrollada con React, TypeScript y Vite. La aplicación permite a los usuarios buscar Pokémon en tiempo real, gestionar un inventario o colección personal de Pokémon y registrar datos de usuario dentro del sistema.   Para poder agregar y gestionar Pokémon en el inventario, es requisito obligatorio contar con un entrenador registrado; de lo contrario, el sistema no permitirá ingresar ningún Pokémon al inventario.

La aplicación consta de 3 páginas principales:

Registro 

 En este apartado, el usuario debe ingresar y registrar sus datos como entrenador. Este registro es indispensable, ya que sin un entrenador activo, el sistema bloqueará las funciones de agregar o modificar Pokémon en la mochila.

Buscador 

En esta sección, el entrenador puede buscar los Pokémon de su preferencia. Al encontrar el Pokémon deseado y verificar sus características, el usuario tiene la opción de incluirlo directamente en su mochila / inventario.

Inventario 

En este apartado se muestran todos los Pokémon que el entrenador ha seleccionado y guardado previamente. Además de permitir la visualización de su colección, esta página le brinda al usuario la opción de eliminar o quitar cualquier Pokémon que ya no desee conservar en su inventario.

Pasos de  Ejecución

Abrir la terminal y navegar a la carpeta del proyecto:

cd TALLER_REACT_POKEMON--main/Buscador-Pokemon-React

Iniciar el servidor de desarrollo:

npm run dev

Abrir la aplicación en el navegador:
Ingresa a la dirección que te ejecuta la consola (por ejemplo, http://localhost:5173). y al ingresar en esta direcciòn te ejecuta directamente el proyecto
